# Sound sources

The three WAV files in this directory are from Benjamin Burnes' **Keyboard
Sounds (Mar 2021)** collection, mirrored in
[Silentnoob21/cc0-public-domain-sounds](https://github.com/Silentnoob21/cc0-public-domain-sounds).

| ThocKey pack | Local file | Original file |
| --- | --- | --- |
| Creamy | `creamy_key.wav` | `Keyboard - Key 1.wav` |
| Clicky | `clicky_key.wav` | `Keyboard - Key 2.wav` |
| Quiet | `quiet_key.wav` | `Keyboard - Key 4.wav` |

The source collection and its included pack readme place these sounds under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).
They may be used, adapted, and redistributed, including in commercial apps;
attribution is not required. The source readme credits Benjamin Burnes
(`abstractionmusic.com`) as the creator and notes that credit is appreciated.
